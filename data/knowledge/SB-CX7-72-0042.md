# SB-CX7-72-0042: Fan blade root coating inspection

| Field | Value |
|---|---|
| Document | SB-CX7-72-0042 |
| Type | Service bulletin |
| Effective | 2026-10-01 |
| Applies to | Contoso Aero Engines CX-7 |

## Reason

Engines removed for fan vibration showed fan blade root coating loss. The affected blades come
from fan blade set lot **FBL-2501-117** (Litware Composites), accepted under deviation
**DEV-2025-007** with coating below the 92 um minimum. The lot has been quarantined since
2026-09-22.

## Affected engines

CX-7 engines whose fan module contains a blade set from lot FBL-2501-117. These engines were
built between 2025-01-13 and 2025-03-21.

## Required action

1. Borescope the fan blade roots within 25 cycles of this bulletin.
2. Repeat every 25 cycles.
3. Coating loss on more than 6 blades, or any fretting: remove the engine and replace the fan blade set.
