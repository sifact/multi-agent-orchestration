# knowledge.py

Writes the knowledge agent's Markdown corpus of procedures and service bulletins.

* Builds ten fictional Contoso documents from the same constants the data uses.
* Sets health-monitoring trend limits calibrated on the real C-MAPSS drift.
* Closes each planted story with a service bulletin naming lot, station, window and action.
* Marks every document fictional and not for operational use.
* Replaces the folder's Markdown files on each build so removed documents do not linger.
